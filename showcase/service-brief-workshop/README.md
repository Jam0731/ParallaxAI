# Write a service brief your AI can actually use

Complete English text package for a 12-minute mini-lesson for freelancers and consultants. Version 1, prepared 2026-10-18.

The learner makes a six-field service brief from supplied facts, marks unanswered questions and removes invented promises. A clear brief can help make a page understandable; it does not guarantee sales.

## Files and delivery order

| File | Purpose | Audience |
|---|---|---|
| `01_teaching-script.md` | Complete spoken narration, screen directions, exact demonstration inputs, expected results, transitions and 12-minute lesson map. | Instructor / producer |
| `02_worked-example.md` | Fieldwork source card, staged document edits, complete brief and optional drafting instruction. | Instructor display; may be shared after the demonstration |
| `03_learner-worksheet.md` | Fresh Quiet Lane exercise, complete raw input, blank six-field brief, self-check and exit response. | Learner — distribute this for practice |
| `04_instructor-key.md` | Separate repaired Quiet Lane brief, reasoning, acceptable alternatives, rubric and feedback guidance. | Instructor — reveal the model brief only after independent practice |
| `05_trial-feedback.md` | Small-trial plan, short feedback form, blank observation table and revision rules. | Instructor / pilot organizer |
| `06_example-service-brief.txt` | Copy-ready completed Fieldwork brief, identical to the final worked-example block. | Demonstration / later drafting input |

The script stops at producing and checking the brief. It does not depend on any particular AI platform or require a paid tool. Use an ordinary text editor or a printed worksheet.

## What is ready

- Complete teaching text, one continuous worked example, fresh learner practice, separate answers and trial materials have been written as real files.
- Both cases are explicitly fictional. Reserved example addresses are not treated as real contact destinations.
- Missing Quiet Lane buyer and additional exclusions remain visible questions. Its price, output formats, one revision, conditional timing and own-show experience are preserved.
- The script explains the difference between a mail link, a real submission destination and a verified inquiry route. No contact action is performed.
