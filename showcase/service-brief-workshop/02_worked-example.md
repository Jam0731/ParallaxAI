# Fieldwork Studio — instructor display materials

Fictional teaching example. This is not a real business, customer case or evidence of results. The email address is reserved for examples. These blocks support one continuous brief; append each stage to the same document.

## Source card

Fieldwork Studio helps independent design studios with 3–12 people organize handoffs from approved design to implementation.

Handoff Reset is a two-week project for one workflow at a fixed USD 1,150. Deliverables are a 60-minute discovery session, current-handoff map, reusable checklist and decision log, and 45-minute team walkthrough. Two revisions of those documents during the project are included.

The client supplies an anonymized recent project and one decision-maker.

The service excludes running client projects, software implementation, HR process changes and ongoing support.

Mira Rowan previously coordinated delivery in a six-person studio for four years. No customer testimonials, logos or quantified results are available.

Contact: studio@fieldwork.example. This is a reserved fictional address, not a real inquiry destination.

Source notes: a mailto link opens the visitor's mail application; it does not send a message. A form needs a real submission destination. An absent destination is a pre-publication gap, not a successful inquiry system.
