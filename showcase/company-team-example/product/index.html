How to use this planner
  1. Choose the fictional example or start blank. Those buttons replace the current scenario; export first to keep a copy.
  2. Enter total monthly hours, non-client hours and a buffer. Enter 0 explicitly for anything that does not apply.
  3. Add each client’s name, monthly hours and fee in USD. Use your own estimates; this planner does not track work.
  4. Add a prospect as another row. Check the remaining or overbooked amount before committing.
  5. Export the readable JSON file for a backup or handoff. The current version restores automatically from this browser only; JSON file import is not included.

Fees are revenue, not profit or guaranteed receipts. This is a single-person planning estimate, not payroll, invoicing, timesheets or a team scheduling system.
